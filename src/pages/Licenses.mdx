## Privacy

No accounts, no cookies, no tracking. Everything runs in your browser.

- **Local storage only.** The game saves your preferences and progress to your browser's `localStorage` — specifically: your player name, mute setting, time control preference, and bot ladder progress (current tier and best streak). None of this data leaves your device and we have no server-side access to it.
- **No analytics.** We run no analytics scripts and set no tracking cookies.
- **Self-hosted fonts.** All fonts are bundled with the app and served from the same origin — no request is ever made to Google Fonts or any third-party CDN, so no external server can log your IP address. No external network request carries any identifiable data.
- **Fairy-Stockfish (offline).** In the installed app the computer opponent runs **entirely on your device** — a native Fairy-Stockfish engine bundled inside the app. No game data is transmitted anywhere. (In the browser/dev build it talks to a local engine on your own machine; still no external server.)

## Game Engine — Fairy-Stockfish

The computer opponent is powered by **[Fairy-Stockfish](https://github.com/fairy-stockfish/Fairy-Stockfish)**,
a chess-variant engine derived from **[Stockfish](https://github.com/official-stockfish/Stockfish)**.
Gridlock Chess runs Fairy-Stockfish to analyze our custom `gridlock` variant; all of our game
rules (charges, Gridlock, Override) are enforced by our own code on top of it. The installed
Android app bundles a build of Fairy-Stockfish compiled for Android (ARM64) using the
[Android NDK](https://developer.android.com/ndk). This build includes a modification: a custom
`fuel` UCI command that communicates per-piece charge state to the engine, enabling charge-aware
search for the Gridlock variant. The desktop/dev build connects to a local engine proxy running
a similarly modified binary.
